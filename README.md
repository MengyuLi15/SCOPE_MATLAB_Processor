# 🌊 SCOPE-MATLAB Processor

**SCOPE (Surface–Carbon–Optics–Profiling Environment)** MATLAB Processor  
A collection of MATLAB modules developed for processing, quality-controlling, and analyzing **BGC-Argo biogeochemical float data**, focusing on the coupling between optical, biological, and carbon-cycle parameters in the open ocean.

---

## 📦 Repository Overview

This repository provides modular MATLAB toolboxes to process multiple BGC-Argo biogeochemical variables and derive ecosystem and carbon-related indicators.  
Each subfolder corresponds to a standalone processing module.


Each module can be executed independently or integrated into a full workflow.

---

## ⚙️ Dependencies

- MATLAB **R2024b** or newer  
- Required toolboxes:
  - **Statistics and Machine Learning Toolbox**
  - **Mapping Toolbox** (optional, for geolocation and section plots)
- BGC-Argo NetCDF files (Core or BGC-Argo profiles)
- Optional: access to [Argo GDAC](https://www.usgodae.org/argo/argo.html) for downloading float data
